🚀 Important: animations should NOT hurt SEO/performance

The document specifically requires mobile-friendly, fast-loading pages and Core Web Vitals, so I would use performance-friendly CSS/JS animations, rather than putting heavy animations everywhere.

The goal should be:

Premium motion, not distracting motion.

So:

No excessive video backgrounds

No huge JavaScript animation libraries unless necessary

Lazy-load portfolio images

Optimize images

Respect prefers-reduced-motion

Keep animations GPU-friendly

Animate mainly transform and opacity

Keep mobile animations lighter
